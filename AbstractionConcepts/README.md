# Abstraction Concepts in Java

This folder contains Java programs to practice the Abstraction concept.

## Topics Covered
- Abstract Class
- Abstract Methods
- Method Overriding
- Static Methods in Abstract Class
- Multilevel Inheritance
- Real-world Examples

## Programs
- Vehicle → Bike
- Electronics → Mobile → Apple
- Electronics → Mobile → Samsung

## Concepts Learned
- Hiding implementation details
- Showing only essential features
- Using abstract classes and methods
- Overriding abstract methods
- Using static methods inside abstract classes
